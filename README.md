# Truller Reboques — Site institucional

Projeto estático pronto para publicação no GitHub Pages.

## Estrutura

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/`

## Publicação

Envie todo o conteúdo desta pasta para a raiz de um repositório público e ative o GitHub Pages em **Settings → Pages → Deploy from a branch → main / root**.
